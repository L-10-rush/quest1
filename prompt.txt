NOTE — Format upgrade
--------------------------------------------------------------------------------
Everything below this line is logged as an engineered prompt rather than a
pasted chat message: GOAL states the outcome wanted, CONSTRAINTS states the
non-negotiables the solution had to respect, and PROMPT is the cleaned-up
instruction actually given to the model. The intent is for this file to
double as a reusable spec, not just a chat transcript.
